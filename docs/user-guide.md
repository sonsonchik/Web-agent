# Руководство пользователя Web Agent

## 1. Назначение
Web Agent — консольное приложение на C++, которое:
- регистрируется на сервере;
- периодически запрашивает задания;
- выполняет поддерживаемые задания;
- отправляет результат и файлы обратно на сервер.

## 2. Быстрый запуск

### macOS / Linux
```bash
cmake -S . -B build
cmake --build build -j
./build/web_agent
```

### Windows (PowerShell)
```powershell
cmake -S . -B build
cmake --build build --config Release
.\build\Release\web_agent.exe
```

## 3. Требования
- CMake 3.14+
- Компилятор с поддержкой C++17
- libcurl
- Доступ к серверу API

`nlohmann/json` подтягивается автоматически через `FetchContent`.

## 4. Конфигурация
Основные файлы:
- `config/agent_config.yaml`
- `config/agent.conf`

Что важно в runtime:
- `uid` агента (генерируется/читается автоматически);
- `access_code` (сохраняется после успешной регистрации);
- директории `logs/`, `tasks/`, `results/`.

## 5. Жизненный цикл агента
1. Запуск и инициализация логгера.
2. Загрузка/создание `uid`.
3. Проверка соединения с сервером.
4. Регистрация (если нет `access_code`) или использование сохраненного.
5. Цикл опроса заданий.
6. Выполнение задания.
7. Отправка результата.

## 6. Поддерживаемые задания
См. подробный документ: [Описание опций заданий](./task-options.md).

На текущий момент поддержаны коды заданий:
- `CONF`
- `GET_FILE`

Для этих кодов агент формирует файл результата `results/result_<session_id>.txt`.

## 7. Логи и диагностика
- Основной лог: `logs/agent.log`
- В логе есть этапы регистрации, опроса, выполнения и отправки результата.
- Остановка приложения: `Ctrl + C` (graceful shutdown).

## 8. Типовые проблемы
- Сервер недоступен: проверить URL/сеть/VPN.
- Ошибка регистрации: проверить уникальность агента и корректность среды.
- Ошибка записи файла: проверить права доступа и наличие директории проекта.

## 9. Обновление и релизы
Платформенные релизы публикуются через GitHub Actions в GitHub Releases при создании тега формата `vX.Y.Z`.

Пример:
```bash
git tag v1.0.0
git push origin v1.0.0
```

После этого автоматически будут собраны и приложены артефакты для Linux, macOS и Windows.
